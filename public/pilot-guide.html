SecondBrain Pilot Guide

This pilot is for testing reliability, usefulness, privacy controls, and real usage cost before public launch.

Your first session

  1. Ask the assistant one real question you would normally ask an AI assistant.
  2. Create one task you genuinely want to remember.
  3. Save one memory or preference.
  4. Upload a small non-sensitive document and try document Q&A.
  5. Optionally connect Google or GitHub if the integration is useful to you.

Completing any three of these counts as onboarding completion.

What to test over 7 days

Use the app naturally. Pay attention to response speed, wrong or confusing answers, missing information, broken actions, privacy concerns, and anything that feels unnecessarily difficult.

Report issues

Open Settings → Send pilot feedback. Use Critical only for security/privacy loss, account/data isolation failures, destructive data loss, or a completely unusable core product. Use High for serious broken workflows without a safe workaround.

Please avoid sensitive data

This is still a closed pilot. Do not upload passwords, financial credentials, highly confidential employer data, medical records, government IDs, or other information you would not want in a pre-launch test environment.

What happens next

The pilot is reviewed daily and at Day 1, Day 3, and Day 7. The cohort is expanded only when activation, latency, cost, reliability, and feedback remain within the pilot thresholds.
